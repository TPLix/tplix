# TPLix v1.0.0 — First Stable Release

**Release Date:** November 8, 2026  
**Release Type:** Stable Release  
**License:** GNU LGPL v3.0

We're excited to announce the first stable release of **TPLix**, a flexible, lightweight, and fast PHP template engine designed to simplify dynamic web application development.

TPLix provides a clean separation between application logic and presentation, making PHP template development more organized, maintainable, and efficient.

## Highlights

- **Lightweight & Fast:** Designed for efficient template processing with minimal overhead.
- **Smarty-Inspired Syntax:** Familiar template syntax for developers experienced with Smarty.
- **Flexible Template Processing:** Supports dynamic rendering of PHP-based templates.
- **Clean Code Separation:** Keeps presentation logic separate from application logic.
- **PHP Integration:** Designed to integrate into existing PHP applications.
- **Composer Support:** Install and manage TPLix through Composer.
- **PSR-4 Autoloading:** Supports modern PHP autoloading standards.

## Installation

Install TPLix using Composer:

```bash
composer require tplix/tplix
```

## Requirements

- PHP (compatible with the minimum version specified in `composer.json`)
- Composer
